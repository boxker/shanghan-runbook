# 伤寒论 Runbook

> 面向《伤寒论》初学者的 Web 学习平台与 Runbook 手册。  
> 当前版本：**v0.3.2**

## v0.3.2

这一版从“扩充内容”转向 **内容质量与学习闭环**，不重复 v0.3.1 已经完成的页面和审核骨架。

### 异文说明

条文 frontmatter 新增可选字段：

```text
variantNotes
```

用于记录不同底本、字形、标点或编号差异。条文详情页会在“来源与校审”区域公开展示；没有明确异文时不会伪造差异。

### Runbook 扩充

太阳篇 Runbook 新增或加强这些学习分叉：

- 桂枝汤连续条文关联
- 桂枝加葛根汤：汗出恶风 + 项背强
- 麻黄汤：无汗、身痛等组合
- 大青龙汤：无汗身痛基础上的烦躁分叉
- 小青龙汤：心下有水气、咳喘/干呕分叉
- 麻黄杏仁甘草石膏汤：发汗后“汗出而喘、无大热”的文本定位

结果页现在可直接进入对应方剂详情和代表条文。

### 方剂对比学习题

每个对比页增加：

- 为什么容易混淆
- 辨别顺序
- 至少 3 道自检题
- 回到代表条文继续核对

CI 会阻止缺少上述学习结构的对比内容合入。

### 太阳篇继续补充

新增第 63 条和 **麻黄杏仁甘草石膏汤** 学习条目，新增内容保持 **草稿** 状态，等待人工初校，不因 AI 辅助录入自动升级审核等级。

### 内容规模

内容源：

```text
content/
├── clauses/
├── formulas/
└── comparisons/
```

构建时自动校验：

```bash
npm run content:check
npm run build
```

## 内容来源

项目把古籍原文、现代学习解释、审核状态分开管理。

公开交叉核对来源之一为 **中国哲学书电子化计划《伤寒论》**。其页面提供包括《四部丛刊初编》本《注解伤寒论》等电子底本。不同版本可能存在编号、异体字与个别文字差异，因此新增内容会先进入草稿流程，而不是直接标为已校。

## 下一步

- 逐步扩充阳明、少阳、太阴、少阴、厥阴核心条文

## 医疗安全声明

项目用于中国传统医学经典的文本、历史概念和辨证思维学习。

不提供个人疾病诊断，不根据症状自动生成处方，也不建议自行使用麻黄、附子、细辛等存在明确风险的药物。真实疾病应由专业医疗人员结合病史、体征和现代医学检查进行判断。
